# 双平台协同多目标跟踪系统 — 设计计划

## 背景
基于 MATLAB 构建双观测平台协同多目标跟踪系统。每个平台仅提供纯方位角（角度）量测数据。系统采用三角测量法进行位置估计，使用 UKF（无迹卡尔曼滤波）处理非线性滤波，使用 JPDA（联合概率数据关联）进行量测-目标数据关联。

## 系统架构

```
[平台1]  ----方位角----\
                          >-- JPDA --> UKF（每目标） --> 航迹输出
[平台2]  ----方位角----/
```

## 文件结构

```
bearing_tracking_system.m       -- 主脚本，包含所有子函数
```

## 详细设计

### 1. 常量与参数
- 仿真时间：T = 100s，步长 dt = 1s
- 2 个固定位置的观测平台：平台1 = [0, 0]，平台2 = [1000, 0]（米）
- 2 个目标，采用不同运动模式（CV 匀速模型）
- 过程噪声协方差 Q，量测噪声协方差 R（方位角标准差 ~1°）
- 检测概率 Pd = 0.9，杂波密度 lambda_c

### 2. 目标状态模型（CV — 匀速运动）
- 状态向量：x = [pos_x, pos_y, vel_x, vel_y]^T
- 状态转移矩阵：F = [1 0 dt 0; 0 1 0 dt; 0 0 1 0; 0 0 0 1]
- 过程噪声协方差 Q（离散白噪声加速度模型）

### 3. 量测模型（非线性）
- 平台 i 位于 (px_i, py_i)，量测目标方位角 (tx, ty)：
  - z_i = atan2(ty - py_i, tx - px_i) + 噪声
- 每个平台对每个被检测到的目标产生 1 个方位角量测值
- 每帧总观测量：2 平台 ×（检测目标数 + 杂波数）

### 4. UKF（无迹卡尔曼滤波）
- 每条航迹/目标对应一个 UKF 实例
- Sigma 点数量：2n+1 = 9 个点（状态维度 n=4）
- UT 参数：alpha=1e-3, beta=2, kappa=0
- 预测步：将 sigma 点通过状态转移方程传播
- 更新步：将 sigma 点通过非线性量测函数传播

### 5. 三角测量（航迹初始化）
- 已知两平台方位角 θ1, θ2：
  - 计算两条方位线的交点
  - 求解：tan(θ1) = (y - py1)/(x - px1)，tan(θ2) = (y - py2)/(x - px2)
  - 初始速度设为 [0, 0]
  - 初始协方差设较大值，反映高不确定性

### 6. JPDA（联合概率数据关联）
- 确认波门：基于量测残差协方差的椭圆波门
- 每帧构建确认矩阵 Ω（目标 × 量测）
- 枚举可行的联合关联事件（假设枚举法）
- 计算每个量测-目标对的边缘关联概率 β_jt
- 每个目标的组合新息：由落入波门内的所有量测加权求和得到
- UKF 更新步使用该组合新息

### 7. 主仿真循环（每时间步 k）

1. **目标真值传播**：按 CV 模型 + 过程噪声推进目标状态
2. **量测生成**：计算真实方位角，叠加噪声，生成杂波
3. **JPDA 关联**：波门筛选量测，计算 β_jt
4. **UKF 预测**：所有已有航迹预测至时刻 k
5. **UKF 更新**：各航迹使用 JPDA 组合新息进行更新
6. **航迹管理**：初始化新航迹，删除丢失航迹
7. **性能评估**：计算 RMSE

### 8. 输出与可视化
- 真实轨迹 vs 估计轨迹（二维图）
- 方位角量测随时间变化图（每平台一个子图）
- 位置 RMSE 随时间变化图
- 航迹关联展示

## 关键函数（在主脚本中实现）

| 函数 | 功能 |
|------|------|
| `generateSigmaPoints(x, P, alpha, beta, kappa)` | 生成 UT sigma 点 |
| `ukfPredict(x, P, F, Q)` | UKF 预测步 |
| `ukfUpdate(x, P, Z_combined, R, plat_pos)` | UKF 更新步（含 JPDA 组合新息） |
| `measurementBearing(state, plat_pos)` | 方位角量测函数 |
| `triangulate(bearing1, bearing2, plat1, plat2)` | 三角测量初始化 |
| `jpdaAssociate(tracks, measurements, plat_positions)` | JPDA 关联主函数 |
| `feasibleEvents(validation_matrix)` | 枚举可行联合关联事件 |

## 验证方法

1. 运行仿真，检查估计航迹是否跟随真实目标
2. 检查 RMSE 是否随时间降低（滤波器收敛性）
3. 验证目标交叉时 JPDA 是否正确关联量测
4. 测试不同噪声水平和杂波密度下的表现
5. 目视检查轨迹图是否合理
