# 多目标跟踪数据关联算法对比 — 实现计划

## 1. 先回答：都有哪些数据关联算法

在**量测-航迹关联**层面，MTT 的算法可按判决形式分为五类。下表同时给出与本系统（双站纯方位、IMM-UKF、每航迹单滤波器、逐帧 CI 融合）的适配性：

| 类别 | 算法 | 核心思想 | 复杂度 | 本系统适配性 / 本期是否实现 |
|---|---|---|---|---|
| 硬判决 | NN（局部最近邻） | 每条航迹独立取波门内似然最大的量测 | O(nm) | 可直接替换 β；允许量测复用；**实现** |
| 硬判决 | GNN（全局最近邻） | 匈牙利/拍卖求全局互斥最优分配 | O((n+m)³) | 可直接替换 β；标准硬判决基线；**实现** |
| 硬判决 | JCBB | 联合相容分支定界，检验多航迹-量测组合 | 指数+剪枝 | 航迹独立时≈GNN，收益有限；不实现 |
| 硬判决 | S-D / MDA | 滑窗内多维分配（Lagrange 松弛） | 高 | 需多帧缓存；不实现 |
| 软判决 | PDA | 单航迹对门内量测贝叶斯加权 | O(nm) | 可直接替换 β；多目标逐航迹独立、允许复用；**实现** |
| 软判决 | JPDA | 枚举联合事件后边缘化 | O((m+1)ⁿ) | 现有实现；**作为基线保留** |
| 软判决 | Cheap JPDA | 近似边缘化，避免事件枚举 | O(nm)~O(nm²) | 可扩展性对照；首版不实现，文档说明 |
| 软判决 | SJPDA | 集合约束下优化 β，禁止量测复用 | 迭代 | 首版不实现 |
| 软判决 | PMHT | EM 把关联当缺失数据 | O(nm·iter) | 需已知目标数；首版不实现 |
| 多帧假设 | MHT（HOMHT/TOMHT） | 假设树 + N-scan 剪枝，延迟判决 | 高 | 需假设级滤波 + 双站融合重构；**后续** |
| 多帧假设 | 滑窗 JPDA | 窗口内联合事件 | 高 | 同 MHT；后续 |
| 随机集 | GM-PHD / CPHD | 传播多目标后验矩，无需显式关联 | 中高 | 纯方位非线性实现复杂；后续 |
| 随机集 | PMBM / δ-GLMB | 检测-关联-出生联合建模，当前 SOTA | 很高 | 后续 |
| 随机集 | LM-IPDA / LM | O(nm) 近似多目标滤波 | O(nm) | 非线性扩展复杂；后续 |
| 本系统特色 | 双站三角交会配对 | 两站方位先交会出位置，再做位置域关联 | O(n₁n₂) | 会改变双站顺序处理结构；首版不实现 |
| 特征辅助 | 级联特征似然 | `L_total = L_kin × L_feat` | — | 不是独立关联器，作为所有方法的公共因子（开/关） |

**选型结论**：本期实现 **NN / GNN / PDA / JPDA** 四种（统一套在现有 IMM-UKF、波门、航迹管理、双站 CI 融合之上，只替换 β 的产生方式），并以**频谱特征开/关**作为第二因子。理由：

- 四种方法输出同一格式的 β 向量，`imm_update` 无需改动，比较是严格受控的（只有关联层不同）。
- 覆盖硬判决/软判决、局部/全局、独立/联合事件三类典型思路，是论文中最常见的对照组合。
- JPDA 精确枚举在 2 目标场景事件数 <100、单帧耗时可忽略；其指数爆炸用单独复杂度基准展示。

MHT / PMHT / PMBM 需要“假设级滤波”或“多帧缓存”，与当前“每航迹单滤波器 + 逐帧 CI 融合”架构冲突；若把它们塞进现有 β 接口，会同时改变关联与融合，无法做公平对比，因此本期只在文档中综述并说明原因。

## 2. 现状核查（代码事实）

- 关联入口：`jpda_process_platform.m` → `jpda_associate.m` → `feasible_events.m`；β 为 `[β0; β1..βm]`，`imm_update` 用 β 加权新息并更新模型概率。
- 双站独立关联：平台 2 在“未含平台 1 更新”的预测副本上再跑一次，后接逐模型 CI 融合。
- 特征：`jpda_associate` 内 `L_total = L_kin × exp(γ(ρ_lofar²+ρ_demon²))`，特征只进关联、不进状态。
- 事件数实测（门概率 0.6）：2×5=26、3×8=225、4×10=1,481、5×12=23,269、6×15=377,908（1.84 s）、8×20=43,276,556（194.6 s）。
- 单次 `run_simulation`（maneuver，2 目标，关特征）≈1.9 s，GOSPA≈33.1 m。
- 量测结构体目前只有 `.bearing`/`.spectrum`，没有“来源目标”标记，无法计算关联层指标。
- `mobile_platforms=true` 时 ECM 用航迹估计决定平台航向 → 不同关联方法的平台轨迹不同、量测序列也不同，不能做严格配对比较。
- `gospar.m` 内含自足的 `hungarian_square` 局部函数（本任务可复用，无需新依赖）。

## 4. 设计决策

1. **β 是唯一接口**：四种方法只决定 β，状态更新、模型概率、融合、航迹管理完全共用。
2. **受控主实验用固定平台**（`mobile_platforms=false`）：保证同种子下量测序列完全相同，可做配对比较；另设 `seeded` 模式（真值初始化 + `max_new_tracks=0`）排除出生/鬼影，只比较关联+滤波；ECM 开启作为端到端补充（不配对，只报均值±方差）。
3. **默认路径零改动风险**：`assoc_method='jpda'` 时 `process_platform` 直接调用现有 `jpda_process_platform`，不经过新关联器。
4. **特征作为公共因子**：所有方法共用同一乘性特征似然，特征开/关是正交消融因子。
5. **JPDA 上限保护**：`params.assoc_jpda_max_events`（默认 50,000，`Inf` 关闭）用行门数乘积上界预判；超限退化为 PDA 并置 `info.fallback=true`，避免 6+ 目标时挂死；默认 2 目标场景远低于上限，不触发。
6. **量测加 `.src`**（0=杂波，k=目标 k）：唯一的数据结构变更，向后兼容（现有代码全部按字段名取 `.bearing`/`.spectrum`）。
7. **本期不做 MHT/PMBM**：见第 1 节理由；后续若要做，需另立“假设级滤波 + 双站融合”设计。

## 6. 各算法实现细节

### 6.1 公共似然 `association_likelihood.m`

```
v(t,j) = wrap(meas(j).bearing - z_pred{t})          % 与现有一致
gated(t,j) = v²/S_t < params.gate_gamma
L(t,j) = exp(-0.5·v²/S_t) / sqrt(2π·S_t)            % 门外置 0
if params.use_features && track.feature_init
    L(t,j) = L(t,j) · spectrum_likelihood(track, meas(j), params)
```
`spectrum_likelihood` 逐字沿用现有分段 Pearson + `exp(γ(max(0,ρ_lofar)²+max(0,ρ_demon)²))`。JPDA 保留其内联实现不动，仅把特征函数改为调用外部文件，保证数值不变。

### 6.2 NN（局部最近邻）

- 每条航迹在门内取 `argmax_j L(t,j)`；无门内量测则 β0=1，否则 β 对应量测置 1。
- 允许两条航迹选同一量测（这正是 NN 与 GNN 的区别）。
- 平局取最小量测索引，保证确定性。

### 6.3 GNN（全局最近邻）

- 代价：`c_ij = -ln(Pd·L_ij)`；未过门置 `BIG=1e9`；漏检 `c_miss=-ln(max(1-Pd,1e-12))`；杂波 `c_fa=-ln(max(λ_c/2π,1e-12))`。
- 构造 `(n+m)×(n+m)` 方阵（n 航迹、m 量测）：行=航迹+虚拟行，列=量测+虚拟列；
  `A(1:n,1:m)=c`，`A(1:n,m+1:m+n)=c_miss`，`A(n+1:n+m,1:m)=c_fa`，其余 0。
- `hungarian_square` 求最小权完美匹配；实配对中 `c_ij < BIG/2` 才算关联，否则该航迹 β0=1。
- β 为 one-hot；同一量测最多被一条航迹占用。
- 该构造与 `gospar.m` 的部分分配构造同源，已由现有求解器验证数值稳健。

### 6.4 PDA（逐航迹概率数据关联）

- 对每条航迹，门内量测：`e_j = Pd·L(t,j)`；`b0 = (1-Pd)·λ_c/(2π)`。
- 若 `Σe_j > 0`：`β0 = b0/(b0+Σe_j)`，`β_j = e_j/(b0+Σe_j)`；否则 β0=1。
- 该式正是现有 JPDA 事件模型在**单航迹**时的精确边缘化（`λ^m` 因子相消），因此单航迹下 PDA β 应与 JPDA β 完全一致——作为测试基准。
- `λ_c=0` 时 b0=0；`Pd=1` 时 b0=0；均不会出现 0/0（无门内量测时直接 β0=1）。

### 6.5 JPDA（保留现有 + 上限保护）

- `feasible_events` 枚举、事件权重、边缘 β 全部不动。
- 新增可选 `info.n_events`、`info.fallback`；`params.assoc_unassoc_threshold` 替代硬编码 0.5（默认值相同）。
- 枚举前用行门数乘积 `∏(1+row_gate_count)` 做上界预判；超过 `assoc_jpda_max_events` 时调用 `assoc_pda` 并 `warning` 一次，`info.fallback=true`。默认 2 目标场景上界 ≤ 9，不触发。

### 6.6 流水线接入

- `assoc_process_platform.m` 与 `jpda_process_platform.m` 同构：IMM 量测预测 → 关联 → 逐模型 `imm_update` → `imm_combine` → `beta0_last` → 频谱模板更新；仅关联器不同。
- `process_platform.m`：
  - `jpda` → `jpda_process_platform`（原样，默认路径零风险）；
  - 其余 → `assoc_process_platform`。
- `run_simulation.m` / `main.m` 改调 `process_platform`，其余顺序不变。

## 7. 指标与实验设计

### 7.1 指标

**端到端（现有 + 复用）**

- GOSPA 均值/中位数/90 分位、`loc / missed / false` 分解；
- 位置 RMSE、速度 RMSE；
- 失败/崩溃次数。

**关联层（新增 `eval_assoc.m`）**

- 每帧用匈牙利把确认航迹与真值目标配对（阈值 `params.gospa_c`），只统计“该目标在该平台被检测到”的 track-frame；
- 软 β：正确目标质量 `Σ_{j:src=tgt}β_j`、错误目标质量、杂波质量；硬判决正确率（argmax 命中正确源）；
- ID 切换次数（目标→航迹 ID 的逐帧变化）；
- 关联层耗时（只计关联调用，不含 UKF 更新）与 JPDA 事件数。

定义说明：`eval_assoc` 的目标-航迹配对在交叉场景可能歧义，会同时报告配对数与歧义帧数；GOSPA 仍是主指标，关联层指标用于解释差异来源。

### 7.2 实验矩阵

| 模式 | 因子 | 默认规模 | 目的 |
|---|---|---|---|
| `main` | 4 方法 × 特征{关,开} | maneuver，固定平台，30 种子 | 主对比表与配对检验 |
| `seeded` | 4 方法 × 特征关 | maneuver，固定平台，真值播种 + 禁止新生，30 种子 | 排除出生/鬼影，只比较关联+滤波 |
| `gamma` | 7 个 γ × 4 方法 | crossing，固定平台，特征开，20 种子 | 特征从弱到强时 GOSPA 由分离走向重合 |
| `scenario` | 4 场景 × 4 方法 | 固定平台，特征关，10 种子 | 交叉/平行场景下的退化 |
| `clutter` | λ_c∈{0,1,2,3,5} × 4 方法 | 固定平台，特征关，20 种子 | 抗杂波能力与计算量 |
| `ecm` | 4 方法 | 特征开，机动平台，10 种子 | 端到端系统性能（不配对，仅均值±方差） |
| `complexity` | 合成门矩阵 (n,m) 与真实逐帧耗时 | — | 展示 JPDA 指数增长、GNN/PDA 的 O(nm)~O(n³) |

### 7.4 合理性检查（不是预设结论）

- 低杂波、无交叉时四者应接近；
- 杂波升高/交叉时，JPDA、GNN 应优于局部 NN 与独立 PDA；
- 特征开启应提升关联正确率，平行/交叉场景更明显；
- JPDA 逐帧耗时随 (n,m) 增长显著快于 GNN/PDA。
若结果相反，先排查实现（β 归一化、门限、配对映射），不强行解释。

## 8. 测试与验收

`matlab/数据关联算法对比/test_assoc.m`（在仓库根目录执行 `matlab -batch "addpath('matlab'); addpath('matlab/数据关联算法对比'); test_assoc"`）：

1. **β 合法性**：四种方法在随机合成场景下 `β≥0`、`sum(β)=1`、长度 `m+1`。
2. **空输入**：无航迹、无量测、全部量测在门外 → 形状正确、β0=1、`unassoc` 合理。
3. **单航迹一致性**：PDA β 与 JPDA β 数值一致（`max|Δ|<1e-12`）。
4. **GNN 互斥性**：一个量测落入两条航迹波门时，只有一条得到它，另一条 β0=1。
5. **NN 复用性**：同一场景下 NN 允许两条航迹选同一量测。
6. **特征判别**：同方位、不同频谱的两个量测，特征开启时匹配谱的量测获得更高 β。
7. **确定性**：平局时输出可复现。
8. **JPDA 回退**：构造 8 航迹 × 20 量测宽门，设小上限，断言 `info.fallback=true` 且 β 等于 PDA。
9. **GOSPA 回归**：`hungarian_square` 抽取前后，固定数据集上 `[d, comp]` 完全一致（实现开始时先记录参考值）。
10. **默认路径回归**：改动前记录 `rng(42); init_parameters('maneuver', 特征关); run_simulation` 的 GOSPA/RMSE 参考值；改动后断言 `<1e-12`。
11. **冒烟**：`assoc_method='gnn'` 跑 1 个种子无报错；`compare_assoc(struct('mode','main','n_mc',2,'plot',false))` 能跑通。

## 9. 风险、边界与假设

**风险 / 边界**

- **默认路径 bit-for-bit**：若抽取 `spectrum_likelihood`/`update_track_spectrum` 后浮点顺序变化，以回归测试为准；必要时让 JPDA 保留内联实现，仅新方法用公共函数。
- **GNN 大 M**：若所有替代方案代价更差，可能选中大 M 配对；实现中显式检查 `c_ij < BIG/2`，测试覆盖。
- **λ_c=0 / Pd=1**：`log(0)` 用 `max(...,1e-12)` 截断；杂波扫描含 λ_c=0，测试覆盖。
- **JPDA 指数爆炸**：上限保护触发时结果退化为 PDA，`info.fallback` 会统计并在结果文档中标注，不静默。
- **ECM 开时不可配对**：主实验固定平台；ECM 模式只报均值±方差，不做符号检验。
- **关联层指标歧义**：交叉场景的目标-航迹配对可能歧义；报告歧义帧数，结论以 GOSPA 为主。
- **内存**：`sim.assoc_history` 与 `sim.meas_src` 很小（每帧 β 向量 + 来源索引），不存频谱。
- **运行时间**：主实验约 8 min，场景约 6 min，杂波约 13 min，ECM 约 1.5 min；均支持 `save_mat` 缓存。

**假设**

- 一次仿真只启用一种关联算法，两平台使用同一算法。
- 维持 2 目标与现有 4 个场景，不新增真值场景；MHT/PMBM 不在本期。
- 不修改 UKF/IMM/运动模型/CI 融合/航迹管理/`eval_gospa` 的数值逻辑；只改关联层与数据记录。
- 环境为 MATLAB R2024a，不新增工具箱依赖（匈牙利复用现有实现）。
